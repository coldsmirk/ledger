# Labels and i18n

Zero hardcoded strings: everything user-visible flows through the `labels` object (`DataTableLabels`). English defaults ship in the package; a complete Simplified-Chinese preset ships from the `./locales` subpath.

## Configuring

App-wide, the Mantine-native way — theme `defaultProps`, no extra provider:

```tsx
import { DataTable } from "@coldsmirk/ledger-mantine";
import { zhCN } from "@coldsmirk/ledger-mantine/locales";
import { createTheme } from "@mantine/core";

const theme = createTheme({
  components: {
    DataTable: DataTable.extend({ defaultProps: { labels: zhCN } })
  }
});
```

Per instance, pass a partial — anything omitted falls back to the defaults:

```tsx
<DataTable labels={{ empty: "还没有任何记录", searchPlaceholder: "搜索成员…" }} … />
```

The standalone compound components (`DataTable.Search`, `.ColumnsPanel`, `.Pagination`, `.SelectionBar`) render outside the table tree, so each takes its own `labels` prop (and its own theme key — `DataTableSearch` etc. — for app-wide configuration). The built-in pagination bar inherits the table's `labels`.

## The catalog

Two entries are functions (they compose numbers into copy); everything else is a string.

| Group | Key | English default |
| --- | --- | --- |
| Pagination | `paginationSummary(from, to, total)` | `` `${from}–${to} of ${total}` `` |
| | `rowsPerPage` | `Rows per page` |
| Selection | `selectAllRows` | `Select all rows` |
| | `selectRow` | `Select row` |
| | `selectedCount(count)` | `` `${count} selected` `` |
| | `clearSelection` | `Clear selection` |
| Expansion | `expandRow` / `collapseRow` | `Expand row` / `Collapse row` |
| | `expandAll` / `collapseAll` | `Expand all rows` / `Collapse all rows` |
| Columns panel | `columnsPanel` | `Columns` |
| | `resetColumns` | `Reset` |
| | `pinStart` / `pinEnd` / `unpin` | `Pin to start` / `Pin to end` / `Unpin` — logical positions (left/right in LTR, mirrored in RTL) |
| | `pinnedStart` / `pinnedEnd` | `Pinned start` / `Pinned end` — captions over the panel's pinned zones |
| | `groupByColumn` / `ungroupColumn` | `Group by this column` / `Ungroup` |
| | `columnWidth` | `Width` |
| | `columnWidthAuto` | `Auto` — the width placeholder for a column that declares no `size` |
| Column interactions | `resizeColumn` | `Resize column` |
| | `reorderColumn` | `Drag to reorder column` |
| Filters | `filterColumn` / `clearFilter` | `Filter column` / `Clear filter` |
| | `filterPlaceholder` | `Filter…` |
| | `filterRangeMin` / `filterRangeMax` | `Min` / `Max` |
| Search | `searchPlaceholder` | `Search…` |
| States | `loading` / `empty` / `loadingMore` | `Loading` / `No data` / `Loading more` |
| Editing | `editPending` | `Saving` |

Most of these are accessibility labels (`aria-label`s on icon-only controls) — a translated table is also a screen-reader-correct table.

## Writing a locale

A locale is just a complete `DataTableLabels` value; `defaultLabels` is exported for spreading:

```tsx
import { defaultLabels, type DataTableLabels } from "@coldsmirk/ledger-mantine";

export const deDE: DataTableLabels = {
  ...defaultLabels,
  paginationSummary: (from, to, total) => `${from}–${to} von ${total}`,
  rowsPerPage: "Zeilen pro Seite",
  empty: "Keine Daten"
  // …
};
```

Contributions of complete locales belong in `src/locales.ts` (published under `./locales`), following the `zhCN` shape.
